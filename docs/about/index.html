关于

图形程序开发者，桌面与移动两端的实时渲染都做。

这个博客记录三件事：

  1. 读论文 —— 实时渲染方向的论文精读与脉络梳理（ReSTIR 系列、SIGGRAPH 课程、全局光照）
  2. 读源码 —— UE / Godot 渲染器的实现剖析，看工业界怎么把理论落地
  3. 写渲染器 —— 自己从零写一个渲染器的过程，包括踩过的坑

写作原则：能贴代码就贴代码，能给数字就给数字，能复现就写清复现步骤。 不写"某某技术浅析"这类读完什么也没留下的文章。

关注方向#

  • 实时全局光照（ReSTIR / 路径追踪 / 采样与重采样）
  • GPU 架构与性能（统一着色器、warp / occupancy、可见性优化）
  • 跨平台渲染（桌面 IMR 与移动 TBDR 的差异与取舍）
  • 图元管线与几何处理（Nanite 类虚拟化几何、LOD、加速结构）
